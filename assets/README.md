# README banner

`hero.png` is a generated presentation banner based on the existing logo at `TwoFHey/Assets.xcassets/logo.imageset/2fheylogo.png`. It retains the blue/teal 2FA speech bubble and orbit-arrow identity. The original application asset is unchanged.

The banner is branding artwork, not an application screenshot. Its six dots are decorative; they do not represent a real verification code.

The repository's existing example image was not used in the README because it includes a named account and a verification-code example. No Messages access was granted and no private messages were captured for these visuals.

Original application project: [SoFriendly/2fhey](https://github.com/SoFriendly/2fhey). See the existing [CC0 license](../LICENSE).
